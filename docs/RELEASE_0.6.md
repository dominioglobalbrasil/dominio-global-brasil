# Domínio Global — Nota de versão 0.6

- Preservado mapa brasileiro e HUD existente; nenhum novo redesenho visual.
- Exércitos divididos em cinco categorias com lotes, custos, tempos, ataque e defesa.
- Produção simultânea de classes distintas por território, sem duplicação da mesma classe.
- Movimentação de tropas mistas com tempos por unidade e verificação do servidor.
- Batalha com impacto de classe, terreno, fortificação, sinergia e suprimento.
- Consumo de logística em escala nacional por turno: alimentos, combustível e energia.
- Aba de logística, composição do estado e diálogos individuais de produção/movimentação.
- Informações detalhadas de unidades inimigas omitidas da API pública.
- Migração retrocompatível de dados v2/v3 para v4 com backup prévio antes da primeira gravação.
- 33 testes Node incluindo batalhas, suprimentos, migrações, ataques ilegais e cessar-fogo.
- Validação automatizada da interface no computador e celular, com servidor Node real.

**Status:** apenas versão local. Sem deploy.
